THE HANDY BOYFRIEND — ONE-PAGE WEBSITE

Open index.html in a browser to preview the site.

Before publishing:
1. Replace the placeholder WhatsApp link https://wa.me/972500000000 with your real WhatsApp number in international format, digits only.
2. Replace YOUR_EMAIL@example.com in the JavaScript with the email address that should receive booking requests. Until then, the form downloads a booking-request.txt file rather than sending a message.
3. Replace the illustrative testimonial cards with genuine reviews only after you have permission.
4. Confirm your service area, rates, availability, and exact services. Only advertise massage if you are appropriately trained and can legally offer it.
5. Upload the whole folder to a static hosting service (e.g. Netlify, GitHub Pages, or your own hosting). Keep the assets folder alongside index.html.

This is a responsive static website, not a live hosted domain. No customer data is collected by a server.
